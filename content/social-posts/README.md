# Xvault Studio - Social Media Posts

30 posts for LinkedIn and X (Twitter), organized into 5 weeks (6 posts per week).

## Format

Each post has two versions:

- **LinkedIn**: Longer, more detailed. No strict character limit.
- **X**: Under 280 characters. Thread-friendly. Can be posted as a single tweet or expanded into a thread.

## Posting Schedule

| File | Posts | Topics |
|------|-------|--------|
| week-01.md | 01-06 | Writing craft fundamentals |
| week-02.md | 07-12 | The writing process |
| week-03.md | 13-18 | Behind the scenes + platform |
| week-04.md | 19-24 | Story craft + practical tools |
| week-05.md | 25-30 | Platform features + craft closers |

## Tone Notes

- Helpful to writers first. Not a sign-up driver.
- Speak from experience, not marketing.
- No em-dashes.
- X posts are standalone. They don't require reading the LinkedIn version.
